# C++ / Qt 设备数据监控上位机

## FreeRTOS 联动

现在可以双击上一级目录的 `启动设备监控系统.cmd` 启动上位机和 FreeRTOS Windows 设备模拟器。在上位机选择“FreeRTOS 模拟设备”并点击“连接”，可查看数据、状态和报警，并用“模拟传感器故障”“恢复传感器”按钮发送命令。完整说明及模拟和硬件的区别见 `../FreeRTOS/DeviceController/README.md`。

这是基于 Qt Widgets 的独立项目，保留了原扫雷项目；使用 Qt Serial Port、QThread 和自绘实时温度曲线。发布版在 `dist` 文件夹，双击 `device_monitor.exe` 启动。请保持该文件夹内的 DLL 和插件目录完整。

## 使用

1. 默认选择“模拟设备”，点击“连接”，即可观察温度、电压、最近 120 个采样点的温度曲线和设备状态。模拟设备每 250 毫秒生成一帧，经相同帧解析与校验代码处理。
2. 温度达到或超过阈值（默认 45 °C），或者设备状态为 1 时触发报警；恢复正常后显示恢复。曲线固定显示 0–100 °C，超出范围的点显示在边界，数字和日志仍记录原值。
3. 接入符合下述示例协议的设备时，选择“串口设备”，刷新并选择端口与波特率后连接。串口固定为 8 数据位、无校验、1 停止位、无流控。断开后可重新配置。
4. 每次启动生成一个 UTF-8 CSV 文件，位于程序旁的 `logs` 文件夹；包含时间、采样值、设备状态与连接、报警、坏帧事件。界面底部会显示日志创建或写入错误。

## 示例串口协议

**此协议是本项目为模拟联调设计的示例，不代表任何现有 STM32 固件协议。** 真实设备需要按此协议发送，或者修改 `protocol.cpp` 适配设备协议。串口只接收，不发送控制命令。

一帧采用 ASCII：`$DATA,序号,温度,电压,状态*校验\n`；也接受 `\r\n`。序号为 0–4294967295 的无符号整数；温度范围 -100–200 °C；电压范围 0–100 V；状态 0 为正常，1 为设备报警。校验为 `$` 与 `*` 之间全部 ASCII 字节逐字节 XOR 后的两位十六进制数，例如：

```
$DATA,42,23.50,3.30,0*12
```

每帧必须以换行结束；错误校验、字段不合法和过长的帧被丢弃并记录事件。数据可以分批到达，也可以连续发送多帧。

## 构建和验证

需要 Qt 5（Widgets、SerialPort）及兼容的 C++ 编译器。从 Qt 开发环境运行 `qmake device_monitor.pro`，然后运行对应的构建工具。使用本机 Visual C++ 编译时要求 UTF-8 源码支持。

发布版可运行 `device_monitor.exe --self-test` 验证协议和工作线程；`device_monitor.exe --integration-test` 自动验证模拟设备、曲线采样、报警和日志，退出码 0 表示通过。集成测试也会创建日志文件。由于目前没有实际 STM32 或虚拟串口对，硬件串口接收和设备协议尚未经过端到端实测。
